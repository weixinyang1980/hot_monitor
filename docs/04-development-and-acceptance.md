# 开发与验收清单

## 阶段验收

### 1. 基础框架搭建

- [ ] `npm install` 成功
- [ ] 前端开发服务器可启动
- [ ] 后端健康检查返回 OK
- [ ] TypeScript 构建通过

### 2. 数据库设计

- [ ] 首次启动自动创建 SQLite 文件和表
- [ ] 关键词可持久化
- [ ] 重启后数据仍存在
- [ ] 重复 URL 和重复关键词有约束

### 3. 热点数据获取

- [ ] 手动扫描可执行
- [ ] 多个来源适配器可独立失败
- [ ] URL 和内容可去重
- [ ] 采集过程有状态记录

### 4. AI 集成

- [ ] DeepSeek Key 从环境变量读取
- [ ] AI 输出通过 JSON schema 校验
- [ ] 相关性、可信度、分类和理由可展示
- [ ] AI 异常时不会错误发送高可信通知

### 5. 前端 UI

- [ ] 桌面端三栏布局正常
- [ ] 手机端单栏布局正常
- [ ] 关键词增删改启停可用
- [ ] 热点流、空状态、加载和错误状态齐全

### 6. 通知系统

- [ ] 浏览器连接 Socket.IO
- [ ] 新热点实时出现在页面
- [ ] 未读数更新
- [ ] SMTP 配置正确时邮件可发送
- [ ] 邮件失败不影响站内通知

### 7. 测试验收

- [ ] 单元测试通过
- [ ] API 测试通过
- [ ] 去重、AI 解析、通知阈值有测试
- [ ] 人工验证移动端和桌面端
- [ ] 人工验证真实 RSS、网页和 Twitter 配置

## 人工验收场景

1. 新增“AI 编程”，点击立即扫描，看到扫描状态变化。
2. 新增第二个关键词，确认两条关键词都能独立启停。
3. 模拟一个高可信热点，确认站内出现未读通知。
4. 模拟一个低可信热点，确认页面显示风险，不触发高优先级邮件。
5. 刷新页面，确认关键词、热点和已读状态保留。
6. 在手机宽度打开页面，确认无横向滚动和文本溢出。
